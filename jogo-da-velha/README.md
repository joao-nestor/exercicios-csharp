# Jogo da Velha em C#

Um jogo da velha desenvolvido em C# como projeto de prática para consolidar os fundamentos da linguagem.

## Funcionalidades

- Partida entre jogador e máquina.
- Escolha de posições de 1 a 9.
- Verificação de posições ocupadas.
- Máquina com jogadas aleatórias.
- Verificação de vitória para ambos os lados.
- Detecção de empate.
- Opção de reiniciar ou encerrar a partida.

## Tecnologias utilizadas

- C#
- .NET

## Conceitos praticados

- Matrizes multidimensionais (`char[,]`).
- Métodos e parâmetros.
- Estruturas condicionais (`if`, `else` e `switch`).
- Estruturas de repetição (`while` e `for`).
- Variáveis booleanas (`bool`).
- Geração de números aleatórios com `Random`.
- Manipulação de dados pelo console.

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto no terminal.
3. Execute:

```bash
dotnet run
```
