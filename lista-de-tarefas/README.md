# Lista de Tarefas

## Sobre o projeto

Programa de gerenciamento de tarefas desenvolvido em C# com o objetivo de praticar listas, estruturas de repetição, condições e validação de entradas do usuário.

## Funcionalidades

- Adicionar tarefas à lista.
- Impedir a adição de tarefas vazias.
- Exibir as tarefas com numeração.
- Remover uma tarefa específica.
- Remover todas as tarefas.
- Validar entradas numéricas.
- Exibir mensagens para opções inválidas.
- Encerrar o programa pelo menu principal.

## Conceitos praticados

- Variáveis e tipos de dados.
- Listas com `List<string>`.
- Métodos `Add()`, `RemoveAt()` e `Clear()`.
- Propriedade `Count`.
- Estruturas condicionais `if` e `else`.
- Estrutura `switch`.
- Laços de repetição `do-while`.
- Laço `foreach`.
- Validação de entradas com `int.TryParse()`.
- Operadores lógicos.
- Controle de fluxo com `break` e `continue`.

## Tecnologias utilizadas

- C#
- .NET

## Objetivo

Desenvolver uma aplicação de console para praticar a manipulação de coleções, a validação de dados e a criação de menus interativos em C#.
