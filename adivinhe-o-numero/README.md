# Jogo de Adivinhação em C#

Um jogo de adivinhação desenvolvido em **C#**, executado no terminal. O objetivo é descobrir o número secreto gerado aleatoriamente pelo programa.

## Como jogar

1. O programa gera um número secreto entre **1 e 100**.
2. Digite um número para tentar adivinhar.
3. O jogo informa se você deve tentar um número maior ou menor.
4. Você tem até **7 tentativas** para acertar.
5. Ao vencer ou perder, você pode escolher se deseja jogar novamente.

**Atenção:** os números digitados devem estar entre 1 e 100.

## Tecnologias utilizadas

- C#
- .NET

## Como executar

Você precisa ter o .NET SDK instalado.

1. Abra o terminal na pasta do projeto.
2. Execute o comando:

   ```bash
   dotnet run
   ```

## O que pratiquei

Neste projeto, pratiquei conceitos básicos de programação em C#:

- Variáveis e tipos de dados.
- Entrada e saída de dados com `Console`.
- Estruturas condicionais (`if`, `else if` e `else`).
- Laços de repetição (`for` e `do-while`).
- Geração de números aleatórios com `Random`.
- Conversão e validação de entradas com `int.TryParse()`.
- Métodos para organizar o código.
