# Sistema de Notas dos Alunos

## Sobre o projeto

Programa desenvolvido em C# para praticar conceitos básicos de programação por meio do cadastro e da análise das notas de cinco alunos.

## Funcionalidades

- Receber as notas de cinco alunos.
- Armazenar as notas em um array.
- Exibir a quantidade de alunos aprovados.
- Calcular a soma e a média das notas.

## Conceitos praticados

- Variáveis e tipos de dados.
- Arrays.
- Estruturas de repetição `for` e `foreach`.
- Estruturas condicionais `if` e `else`.
- Conversão de dados com `Convert.ToDouble()`.
- Acumuladores e contadores.
- Cálculo de média.
- Estrutura `do-while` para repetir o programa conforme a escolha do usuário.

## Tecnologias utilizadas

- C#
- .NET

## Objetivo

Praticar o armazenamento e o processamento de dados em C#, utilizando arrays, estruturas de repetição, condições e operações matemáticas.
